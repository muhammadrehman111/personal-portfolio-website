# Personal Portfolio Website - MERN Stack

A modern, full-stack portfolio website built with the **MERN Stack** (MongoDB, Express, React, Node.js). This project showcases professional skills, projects, experience, education, and certifications with a beautiful, responsive UI.

## 🚀 Tech Stack

### Frontend
- **Framework:** React 18.3 (TypeScript)
- **Build Tool:** Vite 6.3.5 (Fast HMR & optimized builds)
- **Styling:** Tailwind CSS 4 + PostCSS
- **UI Components:** Radix UI + Material-UI (MUI)
- **Animations:** Motion React
- **Forms:** React Hook Form
- **Icons:** Lucide React
- **Charts:** Recharts

### Backend (Ready for Implementation)
- **Runtime:** Node.js
- **Server:** Express.js
- **Database:** MongoDB with Mongoose
- **Authentication:** JWT (JSON Web Tokens)
- **Deployment:** Docker & Docker Compose

## 📁 Project Structure

## ⚡ Quick Start

### Prerequisites
- Node.js v16+
- npm or yarn

### Installation & Setup

1. **Install dependencies:**
   ```bash
   npm i
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```
   Frontend runs on `http://localhost:5173`

3. **Build for production:**
   ```bash
   npm run build
   ```

## 📦 Available Scripts

| Command | Description |
|---------|-------------|
